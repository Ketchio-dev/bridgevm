## A5 — guest PCM reaches the host CoreAudio ring

Run `~/BridgeVM/runs/a5-live-*`, booted with `BRIDGEVM_HDA=1
BRIDGEVM_HDA_COREAUDIO=1` (the boot runner forwards both). The guest played
Windows Ding five times; on shutdown the sink printed:

```
hda CoreAudio stats: frames_rendered=400948 drops=0 dropped_bytes=0
                     format_drops=0 ring_full_drops=0 callback_errors=3
```

`frames_rendered>0 AND drops==0` — the criterion's exact statement — holds.
`callback_errors=3` matches the quality note the original A5 carried and stays
tracked as such: the errors occur at stream teardown, not during rendering,
and no frames were dropped.

One boot-cost lesson: the stats print on clean process shutdown (the sink's
Drop), so the guest must be shut down gracefully (`shutdown /s /t 3`) or the
counters are never emitted.
