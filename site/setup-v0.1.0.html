Set up Windows in v0.1.0

The Mac download opens in Korean. Once BridgeVM is open, follow the steps for your Windows 11 Arm media. The Korean labels match the buttons in the app.

My Windows media

Install from an ISO

Have your licensed Windows 11 Arm ISO ready and allow about 64 GiB for the guest disk.

  1. Choose the ISO. In the welcome window, choose New Windows VM (새 Windows VM 만들기), then Choose ISO (ISO 선택…). Select your Windows 11 Arm ISO.
  2. Name the VM and prepare its drivers. Type a name in 이름. In this version, “Windows 11” is placeholder text. Choose Download Drivers (드라이버 자동 준비), or select your signed driver folder and its manifest.
  3. Start installation. Choose Create (생성). In the new VM’s detail view, choose Start Installation (설치 시작).

Import an installed disk

BridgeVM copies the installed disk into its library. For a compressed QCOW2 disk, import a RAW copy with this release.

  1. Open the import form. Choose Import an Existing VM (기존 VM 가져오기). Keep the prefilled name “Windows 11” or enter your own.
  2. Choose the installed disk. Next to Windows disk (Windows 디스크), choose 선택… and select your RAW, QCOW2 or VHDX file. If you have its matching UEFI variables file, select it in the separate optional field.
  3. Start Windows. Choose Import (가져오기). Select the saved VM in the library, then choose Start (시작).
