v0.1.0 release notes
Which Macs can run it?

Running a VM requires Apple silicon and macOS 15 or later. The current host test matrix covers M4 and M5. Earlier Apple silicon generations still need validation.

What should I know before installing?

The app is ad-hoc signed and not notarized. The installation guide includes download verification and the first-open steps. Bring your own licensed Windows 11 Arm media.

Read the installation guide
What are the preview limits?

3D acceleration is excluded from General Preview and v1. Hardware tests have observed uneven display updates and audio stutter. ISO setup and disk import on a clean Mac are still under validation.

Known limitations
How are Windows drivers supplied?

During ISO setup, BridgeVM can fetch the signed ARM64 Red Hat virtio-win drivers and verify the pinned SHA-256. BridgeVM does not redistribute these drivers. You may also select your own signed driver folder and manifest.

Where are the engine and test results?

Runs an installed Windows 11 Arm desktop on BridgeVM's own Hypervisor.framework VMM with persistent storage, display/input, network, audio, clipboard and folder integration, TPM/Secure Boot workflows, snapshots and window Coherence verbs. 3D acceleration is excluded from General Preview and v1; release-blocking evidence remains open and known defects are disclosed below.
