Windows 11 Arm ISO

Install Windows

Bring your own licensed ISO and about 64 GiB of free disk space. BridgeVM can download and verify the signed storage, serial and network drivers when you choose automatic driver setup.

Windows setup requirements

RAW, QCOW2 or Hyper-V VHDX

Import an installed disk

Bring a disk with Windows 11 Arm already installed. Choose the installed-disk import in BridgeVM. This setup skips the installer driver payload.

Import requirements

A Windows desktop.

Read known limitations
Graphics

3D acceleration is excluded from General Preview and v1. Vulkan and D3D11 work continues in the experimental Graphics Lab.

Distribution channels
Display, audio and setup coverage

In retained hardware runs, the 3D-off display was choppy and guest audio stuttered. Clean-Mac evidence for ISO installation and installed-disk import remains open.

Windows drivers

Automatic setup verifies the roughly 95 MB signed Red Hat virtio-win payload against a pinned SHA-256. You can also provide your own signed ARM64 drivers and checksum manifest. BridgeVM does not redistribute these drivers or enable Windows TESTSIGNING.

Engine and source builds

Runs an installed Windows 11 Arm desktop on BridgeVM's own Hypervisor.framework VMM with persistent storage, display/input, network, audio, clipboard and folder integration, TPM/Secure Boot workflows, snapshots and window Coherence verbs. 3D acceleration is excluded from General Preview and v1; release-blocking evidence remains open and known defects are disclosed below.
