01 / THE APPROACH

A VM, not a promise
wrapped in a download button.

The engine is real. So are the boundaries. BridgeVM develops a Windows 11 Arm desktop path on Apple silicon, with each claim tied to a declared capability and evidence.

CANONICAL ENGINE SUMMARYRuns an installed Windows 11 Arm desktop on BridgeVM's own Hypervisor.framework VMM with persistent storage, display/input, dynamic resolution, network, audio, clipboard and folder integration, TPM/Secure Boot workflows, snapshots and window Coherence verbs. 3D acceleration is excluded from General Preview and v1; release-blocking evidence remains open and known defects are disclosed below.

02 / IN SCOPE

Built for a specific machine.

Windows 11 Arm on Apple silicon, through a QEMU virt-compatible guest contract with documented deviations. This is not a promise for every Mac or every Windows workload.

PRODUCT STATEEngineering
Preview** Not a published General Preview

Release-blocking evidence remains open. Clean-machine install and import journeys have not been retained as passing product-flow receipts; interrupted-operation coverage and other release gates remain unfinished.

The 3D-off live display has been choppy in recent hardware runs, and guest audio has stuttered. Do not use this page as a substitute for the complete dated status and known-defect record.

04 / TRY THE SOURCE

Start with the code.
Bring your own media.

The current path is a local, ad-hoc-signed development build—not a verified release. You need Apple silicon, macOS 14+, Xcode/Swift 5.9+ and Rust 1.85+.
