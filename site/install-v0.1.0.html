Install BridgeVM on your Mac

Get the v0.1.0 preview for Apple silicon and macOS 15 or later. The Mac app opens in Korean. The English setup steps include the matching Korean button labels.

Download for Mac Build the English app from source

Check your download

Compare the file with the published v0.1.0 checksum before opening it.

Your browser checks the file on this device. The file stays on your Mac.

Verify in Terminal

If you saved the file in Downloads, run this command and compare the first 64 characters with the expected SHA-256.

shasum -a 256 ~/Downloads/BridgeVM-v0.1.0.dmg

Expected SHA-256

57fd4cc99c4218e2c6ad5bfcb3b4ab58073859f6d5f0a4027cecb04ff9486d7b Published checksums

Open the Mac app

  1. Once the checksum matches, open the DMG and drag BridgeVM to Applications.
  2. Open BridgeVM from Applications. This preview is ad-hoc signed and has no Apple notarization.
  3. If macOS says it can’t verify the developer and you trust the download, open System Settings → Privacy & Security. Choose Open Anyway for BridgeVM and confirm.
